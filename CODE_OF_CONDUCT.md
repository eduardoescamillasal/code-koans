# Code of Conduct

Treat people with respect. Welcome contributors across skill levels,
backgrounds, and identities. Critique the work, provide actionable feedback,
give credit, and respect requests for privacy and boundaries.

Harassment, threats, discriminatory language, unwanted sexual attention, and
publishing another person's private information without consent are
unacceptable. This applies to project spaces and to public representation of
the project.

Report incidents privately to a repository maintainer. On GitHub, you can use
the repository's private vulnerability reporting channel for security issues
when enabled, or GitHub's abuse reporting tools for abusive accounts and
content. For other conduct concerns, use a private contact listed on the
maintainer's profile or ask publicly for a private contact without sharing
details. Maintainers should limit access to reports and can remove content,
warn contributors, or restrict participation as appropriate.
